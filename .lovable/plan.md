

# Place in Thyme - Shopify Meal Delivery & Juice Store

## Project Overview
A Shopify-powered online ordering system for Place in Thyme's weekly meal delivery program and juice offerings, featuring rotating weekly menus, subscription ordering, and a branded storefront.

---

## Phase 1: Storefront Foundation

### Branding & Theme Setup
- Custom theme matching Place in Thyme's warm, rustic catering aesthetic
- Color palette inspired by their existing branding (earthy tones, fresh food imagery)
- Responsive design optimized for mobile, tablet, and desktop ordering

### Navigation Structure
- **Home** - Hero section with brand messaging and featured items
- **Weekly Meals** - Rotating menu section with clear ordering windows
- **Juices** - Permanent juice product catalog
- **About** - Company story and Operation Helping Hands mission
- **FAQ / How It Works** - Ordering process, delivery info, cutoff times

- Menu availability toggle system (only one active menu visible at a time)
- Clear display of current week's offerings

### Juice Product Collection
- Permanent catalog of juice products
- Product variants (sizes, flavors as applicable)

## Phase 3: Ordering System

### Weekly Ordering Logic
- **Ordering Cutoff Display** - Clear notification of weekly ordering deadline
- **Delivery Window Info** - Expected delivery date/time display

### Cart & Checkout
- Add to cart functionality with quantity selection
- Cart drawer with item summary
- Secure Shopify checkout integration

### Subscription-Ready Structure
- Product setup compatible with subscription apps
